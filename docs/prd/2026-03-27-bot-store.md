## 1. Visión del Producto

Una plataforma global (marketplace) de bots AI integrada en arclosystems.com donde empresas y profesionales pueden descubrir, personalizar, pagar y activar bots inteligentes para automatizar sus operaciones. La plataforma ofrece un catálogo de bots pre-construidos con personalización self-service, y soporte asistido para necesidades complejas o enterprise.

## 2. Problema

- Las empresas necesitan automatizar tareas repetitivas (atención al cliente, ventas, operaciones) pero no tienen el conocimiento técnico para construir bots propios.
- Las soluciones existentes son genéricas, caras, o requieren desarrollo desde cero.
- En LATAM y Costa Rica en particular, no hay un marketplace local que combine bots AI + integraciones relevantes + pagos locales (SINPE Móvil, tarjetas vía Tilopay).

## 3. Mercado Objetivo

| Segmento | Descripción | Prioridad |
|----------|-------------|-----------|
| PYMEs Costa Rica | Comercios, restaurantes, servicios que quieren automatizar atención al cliente y ventas | Alta |
| PYMEs LATAM | Mercado hispanohablante con necesidades similares | Media |
| Empresas globales | Negocios que buscan bots en inglés o español | Media |
| Enterprise | Grandes empresas con necesidades custom y presupuesto alto | Baja (fase posterior) |

**Idiomas:** Español + Inglés desde el lanzamiento.

## 4. Modelo de Negocio

### 4.1 Suscripción Mensual Fija

| Plan | Precio Sugerido | Incluye |
|------|----------------|---------|
| **Starter** | $29/mes | 1 bot, 1 integración, 1,000 mensajes/mes, modelos económicos (Haiku) |
| **Pro** | $99/mes | 3 bots, 5 integraciones, 10,000 mensajes/mes, modelos avanzados (Sonnet/GPT-4o) |
| **Business** | $249/mes | 10 bots, integraciones ilimitadas, 50,000 mensajes/mes, todos los modelos, soporte prioritario |
| **Enterprise** | Custom | Bots ilimitados, desarrollo custom, SLA dedicado, onboarding asistido |

### 4.2 Procesador de Pagos

- **Tilopay** como procesador principal
- Soporte para tarjetas de crédito/débito y SINPE Móvil
- Facturación recurrente mensual
- Manejo de monedas: USD (global) + CRC (Costa Rica)

### 4.3 Estructura de Costos por Bot

| Modelo AI | Costo Aprox. por 1K mensajes | Uso |
|-----------|------------------------------|-----|
| Claude Haiku 4.5 | ~$0.08 | Bots simples: FAQ, respuestas cortas |
| Claude Sonnet 4.6 | ~$0.80 | Bots intermedios: ventas, soporte contextual |
| GPT-4o | ~$1.25 | Bots avanzados: razonamiento complejo |
| Claude Opus 4.6 | ~$4.00 | Tareas enterprise de alta complejidad |

El margen se genera por la diferencia entre el costo fijo de la suscripción y el costo variable del consumo de tokens. Los planes están diseñados para que el margen sea >60% en el plan Starter y >40% en Business.

## 5. Catálogo de Bots (MVP)

### 5.1 Bots Base para Lanzamiento

| Bot | Descripción | Integraciones | Modelo Sugerido |
|-----|-------------|---------------|-----------------|
| **Atención al Cliente** | Responde preguntas frecuentes, escala a humano cuando no sabe | WhatsApp, Web Chat, Telegram | Haiku |
| **Asistente de Ventas** | Califica leads, recomienda productos, agenda demos | WhatsApp, Email, CRM | Sonnet |
| **Bot de Reservas** | Gestiona citas y reservas con calendario | WhatsApp, Google Calendar | Haiku |
| **Soporte Técnico** | Troubleshooting guiado con base de conocimiento | Web Chat, Slack, Email | Sonnet |
| **Onboarding Bot** | Guía a nuevos usuarios/empleados paso a paso | Slack, Teams, Web Chat | Haiku |
| **E-commerce Assistant** | Búsqueda de productos, estado de pedido, devoluciones | WhatsApp, Shopify, WooCommerce | Sonnet |

### 5.2 Personalización por Cliente

Cada bot base se puede personalizar sin código:

- **Identidad:** nombre, tono de voz, idioma, avatar
- **Conocimiento:** subir documentos (PDF, TXT, CSV), URLs, FAQ manual
- **Flujos:** definir respuestas para escenarios específicos
- **Integraciones:** conectar sus plataformas (WhatsApp Business API, CRM, etc.)
- **Escalación:** reglas de cuándo transferir a un humano

## 6. Arquitectura Técnica

### 6.1 Enfoque: Monolito Modular

Un solo sistema desplegable que internamente está organizado en módulos desacoplados. Permite iterar rápido con un equipo de 4 personas y extraer microservicios solo cuando sea necesario.

### 6.2 Stack Tecnológico

| Capa | Tecnología |
|------|------------|
| Frontend | Next.js 15, TypeScript, Tailwind CSS |
| Backend | NestJS, TypeScript |
| Base de Datos | PostgreSQL + Prisma ORM |
| Cache/Queue | Redis (sesiones, rate limiting, job queue) |
| AI Models | Anthropic API (Haiku, Sonnet, Opus), OpenAI API (GPT-4o) |
| Pagos | Tilopay SDK |
| File Storage | AWS S3 (documentos de entrenamiento) |
| Hosting | Vercel (frontend) + AWS (backend, DB, Redis) |
| Real-time | WebSockets (chat en vivo, notificaciones) |
| Monitoring | Sentry + CloudWatch |

## 7. Modelo de Datos (Core)

```prisma
model User {
  id            String   @id @default(cuid())
  email         String   @unique
  name          String
  company       String?
  language      String   @default("es") // "es" | "en"
  role          Role     @default(CUSTOMER)
  subscription  Subscription?
  bots          Bot[]
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

enum Role {
  CUSTOMER
  ADMIN
}

model Plan {
  id              String   @id @default(cuid())
  name            String   // Starter, Pro, Business, Enterprise
  priceUsd        Decimal
  priceCrc        Decimal?
  maxBots         Int
  maxIntegrations Int
  maxMessages     Int      // mensajes por mes
  aiTier          AiTier   // qué modelos puede usar
  features        Json     // features adicionales
  subscriptions   Subscription[]
}

enum AiTier {
  BASIC      // Solo Haiku
  ADVANCED   // Haiku + Sonnet + GPT-4o
  PREMIUM    // Todos los modelos
}

model Subscription {
  id            String   @id @default(cuid())
  userId        String   @unique
  user          User     @relation(fields: [userId], references: [id])
  planId        String
  plan          Plan     @relation(fields: [planId], references: [id])
  status        SubStatus @default(ACTIVE)
  tilopaySubId  String?  // ID en Tilopay
  currentPeriodStart DateTime
  currentPeriodEnd   DateTime
  createdAt     DateTime @default(now())
}

enum SubStatus {
  ACTIVE
  PAST_DUE
  CANCELLED
  TRIALING
}

model BotTemplate {
  id            String   @id @default(cuid())
  slug          String   @unique
  name          String
  description   String
  category      String
  defaultConfig Json     // configuración base
  systemPrompt  String   // prompt base del template
  icon          String?
  isPublished   Boolean  @default(false)
  bots          Bot[]
}

model Bot {
  id            String   @id @default(cuid())
  userId        String
  user          User     @relation(fields: [userId], references: [id])
  templateId    String
  template      BotTemplate @relation(fields: [templateId], references: [id])
  name          String
  config        Json     // personalización del cliente
  systemPrompt  String   // prompt personalizado
  isActive      Boolean  @default(false)
  integrations  BotIntegration[]
  documents     Document[]
  conversations Conversation[]
  messageCount  Int      @default(0) // contador del período actual
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

model BotIntegration {
  id            String   @id @default(cuid())
  botId         String
  bot           Bot      @relation(fields: [botId], references: [id])
  platform      Platform
  credentials   Json     // encrypted: API keys, tokens
  webhookUrl    String?
  isActive      Boolean  @default(false)
  config        Json?    // configuración específica de la plataforma
}

enum Platform {
  WHATSAPP
  TELEGRAM
  FACEBOOK_MESSENGER
  INSTAGRAM
  SLACK
  TEAMS
  EMAIL
  WEB_CHAT
  SHOPIFY
  WOOCOMMERCE
  HUBSPOT
  CUSTOM_API
}

model Document {
  id            String   @id @default(cuid())
  botId         String
  bot           Bot      @relation(fields: [botId], references: [id])
  filename      String
  s3Key         String
  mimeType      String
  sizeBytes     Int
  status        DocStatus @default(PROCESSING)
  chunks        Int?     // número de chunks después de procesar
  createdAt     DateTime @default(now())
}

enum DocStatus {
  PROCESSING
  READY
  FAILED
}

model Conversation {
  id            String   @id @default(cuid())
  botId         String
  bot           Bot      @relation(fields: [botId], references: [id])
  externalId    String?  // ID del chat en la plataforma externa
  platform      Platform
  messages      Message[]
  status        ConvStatus @default(ACTIVE)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

enum ConvStatus {
  ACTIVE
  ESCALATED
  CLOSED
}

model Message {
  id              String   @id @default(cuid())
  conversationId  String
  conversation    Conversation @relation(fields: [conversationId], references: [id])
  role            MsgRole
  content         String
  model           String?  // qué modelo respondió
  tokensUsed      Int?
  latencyMs       Int?
  createdAt       DateTime @default(now())
}

enum MsgRole {
  USER
  ASSISTANT
  SYSTEM
}
```

## 9. Funcionalidades del Dashboard

### 9.1 Panel del Cliente

- **Mis Bots**: lista de bots activos, estado, uso del mes
- **Configurador de Bot**: editor visual de personalización (nombre, tono, docs, flujos)
- **Integraciones**: conectar/desconectar plataformas con OAuth o API keys
- **Analytics**: mensajes por día, tasa de resolución, temas frecuentes, satisfacción
- **Conversaciones**: historial con búsqueda, opción de intervenir manualmente
- **Billing**: plan actual, uso, facturas, método de pago (Tilopay)
- **Base de Conocimiento**: subir y gestionar documentos de entrenamiento

### 9.2 Panel Admin (Arclo)

- **Usuarios**: gestión de clientes, planes, soporte
- **Templates**: CRUD de bots del catálogo, prompts, configuraciones
- **Métricas globales**: MRR, churn, uso de tokens, costos AI, márgenes
- **Onboarding queue**: clientes Enterprise esperando setup asistido

## 10. Seguridad

- Autenticación JWT + OAuth (Google, GitHub)
- Credenciales de integración encriptadas en DB (AES-256)
- Rate limiting por plan (Redis)
- Aislamiento de datos por tenant (row-level security o filtro por userId)
- HTTPS everywhere
- Logs de auditoría para acciones sensibles
- Cumplimiento con ley de protección de datos de Costa Rica (Ley 8968)

## 13. Riesgos y Mitigaciones

| Riesgo | Impacto | Mitigación |
|--------|---------|------------|
| Costos de AI superan ingresos por suscripción | Alto | Monitoreo de márgenes por plan, rate limiting estricto, uso de Haiku por defecto |
| WhatsApp Business API costosa o difícil de aprobar | Medio | Empezar con Web Chat + Telegram, WhatsApp como feature premium |
| Baja adopción inicial | Alto | Ofrecer trial gratuito de 14 días, contenido educativo, caso de éxito con cliente piloto |
| Competencia (Chatfuel, ManyChat, Botpress) | Medio | Diferenciación: AI moderna (no rule-based), mercado LATAM, pagos locales, soporte en español |
| Equipo pequeño (4 personas) | Medio | Monolito modular para velocidad, priorizar features por impacto, automatizar todo lo posible |
